## About

プロダクト志向で開発基盤を改善する、テックリード / バックエンドエンジニアです。

主に Go と TypeScript を扱い、API 契約、バックエンド設計、データベースを意識した実装、CI/CD、レビューの流れ、実務で使える AI 駆動開発など、チームが前に進みやすくなる領域を改善することに関心があります。

## Focus

- Go を中心としたバックエンド設計・サービス設計
- OpenAPI と型生成による API 契約の改善
- 型付きインターフェースと境界整理によるフロントエンド / バックエンド連携
- データベースを意識した実装、バッチ処理、運用保守
- CI/CD、モノリポ設計、チームへの展開による Developer Experience 改善
- Claude Code / GitHub Copilot を実務に落とし込む AI 駆動開発

## How I Work

- 技術選定の前に、プロダクトと運用の文脈を確認します。
- インターフェースを明確にし、チーム間の認識齟齬を減らします。
- 段階的な移行を好みますが、互換性維持のコストが高すぎる場合は明確に伝えます。
- 技術判断、レビュー、開発プラクティスの共有をしながら、自分でも手を動かします。
