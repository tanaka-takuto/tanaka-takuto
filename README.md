## About

I am a tech lead / backend engineer focused on product-minded platform improvement.

I work mainly with Go and TypeScript, and I like improving the parts of a product that make teams move faster: API contracts, backend design, database-aware implementation, CI/CD, review flow, and practical AI-assisted development.

## Focus

- Backend architecture and service design with Go
- API contract improvement with OpenAPI and type generation
- Frontend/backend alignment through typed interfaces and clearer boundaries
- Database-aware implementation, batch workflows, and operational maintenance
- Developer experience through CI/CD, monorepo planning, and team enablement
- Practical use of Claude Code and GitHub Copilot in real development workflows

## How I Work

- I start from the product and operational context before choosing a technical shape.
- I make interfaces explicit so teams can reduce ambiguity and move independently.
- I prefer incremental migration paths, but I will call out when compatibility costs more than it returns.
- I stay hands-on while leading technical decisions, reviews, and shared engineering practices.
